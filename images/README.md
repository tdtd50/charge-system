# 微信小程序图片资源说明

请在此目录放置以下图片文件：

## 必需的图片

1. **logo.png** (160x160px)
   - 用于登录页面的LOGO
   - 建议使用PNG格式，支持透明背景

2. **charge.png** (81x81px)
   - TabBar未选中状态的充电图标
   - 灰色图标

3. **charge-active.png** (81x81px)
   - TabBar选中状态的充电图标
   - 蓝色图标

4. **user.png** (81x81px)
   - TabBar未选中状态的用户图标
   - 灰色图标

5. **user-active.png** (81x81px)
   - TabBar选中状态的用户图标
   - 蓝色图标

6. **default-avatar.png** (120x120px)
   - 默认用户头像
   - 圆形头像

7. **empty.png** (300x300px)
   - 空状态占位图
   - 用于订单列表为空时显示

## 图片来源建议

- 可以从 iconfont.cn 下载图标
- 可以使用设计工具（如Figma、Sketch）自己设计
- 可以从免费图标网站（如flaticon.com）下载

## 注意事项

- 图片格式建议使用PNG，支持透明背景
- TabBar图标尺寸建议为 81x81px
- 注意控制图片大小，避免过大影响小程序性能
- 确保图片命名与代码中引用的路径一致
