# 充电桩管理系统 - 微信小程序

## 项目说明

这是充电桩管理系统的微信小程序端，用户可以通过小程序进行充电、查看订单、充值等操作。

## 快速开始

### 1. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择当前目录（miniprogram文件夹）
4. 输入AppID（测试可使用测试号）

### 2. 配置服务器地址

修改 `utils/request.js` 文件中的服务器地址：

```javascript
// 本地开发
const BASE_URL = 'http://localhost:5000/api'

// 局域网测试（手机真机）
const BASE_URL = 'http://192.168.1.100:5000/api'  // 改为你的电脑IP

// 生产环境
const BASE_URL = 'https://yourdomain.com/api'
```

### 3. 配置开发者工具

在微信开发者工具中：
- 详情 → 本地设置 → 勾选"不校验合法域名"

### 4. 准备图片资源

在 `images/` 目录中放置所需的图片文件，详见 `images/README.md`

### 5. 运行项目

点击"编译"按钮即可在开发者工具中预览小程序。

## 功能说明

### 登录页面
- 用户使用学号和密码登录
- 测试账号：2021001 / 123456

### 充电页面
- 显示账户余额
- 选择充电金额（1-4元，对应1-4分钟）
- 点击"立即充电"开始充电
- 显示充电倒计时和进度条

### 我的页面
- 显示个人信息（姓名、学号、余额）
- 账户充值功能
- 查看订单入口
- 退出登录

### 订单页面
- 我的订单：查看所有订单
- 充电中订单：查看正在充电的订单
- 已结束订单：查看已完成的订单

## API说明

小程序通过以下API与后端通信：

- `POST /api/user/login` - 用户登录
- `GET /api/user/info/:id` - 获取用户信息
- `POST /api/user/recharge` - 用户充值
- `POST /api/user/charge` - 创建充电订单
- `GET /api/user/orders/:id` - 获取所有订单
- `GET /api/user/orders/charging/:id` - 获取充电中订单
- `GET /api/user/orders/finished/:id` - 获取已结束订单

## 注意事项

1. **网络配置**
   - 开发时勾选"不校验合法域名"
   - 生产环境需要配置HTTPS域名白名单

2. **后端连接**
   - 确保Flask后端正常运行（http://localhost:5000）
   - 手机测试时需使用局域网IP

3. **测试账号**

## 真机测试

1. 确保手机和电脑在同一WiFi
2. 查看电脑局域网IP：
   - Windows: `ipconfig`
   - Mac/Linux: `ifconfig`
3. 修改 `utils/request.js` 中的服务器地址
4. 点击"预览"生成二维码
5. 使用微信扫码在手机上测试

## 常见问题

### 1. 小程序无法连接后端

**解决方法**：
- 检查后端是否运行
- 检查服务器地址是否正确
- 检查是否勾选"不校验合法域名"
- 防火墙是否允许5000端口

### 2. 图片不显示

**解决方法**：
- 检查images目录下是否有对应图片
- 检查图片路径是否正确
- 使用绝对路径（以/开头）

### 3. 登录失败

**解决方法**：
- 检查用户名密码是否正确
- 检查后端数据库是否初始化
- 查看控制台错误信息

## 生产环境部署
